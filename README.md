# road-rage-bot

This is a Discord bot for **ROAD RAGE: the game**, built with [python](https://www.python.org/) and [discord.py](https://pypi.org/project/discord.py/).

## Getting Started

1. Install dependencies using `conda env create -f environment.yaml`.

2. Activate the new environment with `conda activate road-rage-bot`.

3. Create a `.env` file with the `TOKEN`, `PREFIX`, and `MODE` (either `development` or `production`).

4. Run the bot with `python src/main.py`.
